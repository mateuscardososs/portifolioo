# Fontes locais

Este diretório contém apenas os subsets latinos em formato WOFF2 usados pelo site.

| Família | Pacote de origem | Versão | Intervalo usado | Arquivo |
| --- | --- | --- | --- | --- |
| Archivo | `@fontsource-variable/archivo` | 5.3.0 | 500–600 | `archivo-latin-wght-normal.woff2` |
| Source Sans 3 | `@fontsource-variable/source-sans-3` | 5.3.0 | 400–600 | `source-sans-3-latin-wght-normal.woff2` |
| IBM Plex Mono | `@fontsource/ibm-plex-mono` | 5.3.0 | 400 e 500 | `ibm-plex-mono-latin-400-normal.woff2`, `ibm-plex-mono-latin-500-normal.woff2` |

Os três pacotes são distribuídos sob a SIL Open Font License 1.1. As licenças e atribuições originais estão preservadas em `licenses/`. IBM Plex Mono usa dois arquivos estáticos porque o pacote Fontsource não oferece uma distribuição variável dessa família.

As métricas das fontes de fallback foram calculadas com Fontaine 1.0.0 usando Arial para as famílias sem serifa e Courier New para a família monoespaçada.
