Sobre Mim

Olá! Sou Mateus Cardoso, um estudante de Ciência da Computação na UNICAP e um entusiasta da tecnologia em constante evolução. Minha jornada no desenvolvimento de software é movida pela curiosidade e pelo desafio de resolver problemas complexos.

Com uma base sólida em Python para automação e análise de dados, e experiência robusta no Back-end com Java (Spring Boot), PostgreSQL e MySQL, eu me dedico a criar sistemas eficientes e bem estruturados.

No Front-end, utilizo React e JavaScript para construir interfaces de usuário interativas e responsivas que proporcionam excelente experiência ao usuário.

Além do código, tenho grande interesse por práticas DevOps, testes automatizados e o design de APIs RESTful, buscando sempre entregar software de alta qualidade seguindo as melhores práticas da indústria.
